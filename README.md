# Portfolio

Site portfolio personnel, créé avec HTML et CSS sans dépendance ni étape de compilation.

## Aperçu local

Ouvrir `index.html` dans un navigateur. Les modifications HTML et CSS sont visibles en rechargeant la page.

## Publication

Le site est destiné à être publié gratuitement avec GitHub Pages. La configuration de la publication sera ajoutée après la création du dépôt GitHub.
